## Шаг 1 — Flutter (на твоём ноутбуке)

```powershell
cd MonoRepForCafeConn\CafeConn

# 1. Проверка кода (у меня в песочнице нет Dart SDK — этот шаг обязателен)
flutter analyze
flutter test

# 2. Если analyze чистый — собрать веб-сборку персонала
flutter build web --release --base-href /staff/

# 3. Скопировать сборку в Django
Copy-Item -Recurse -Force .\build\web\* ..\CafeConnWeb\static\staff\
```

Если `flutter analyze` показал ошибки — не чини руками, отдай Claude Code промт из Шага 3.

## Шаг 2 — Docker (обновить сервер)

```powershell
cd MonoRepForCafeConn\CafeConnWeb

# Код Python/шаблоны/CSS примонтированы volume'ом — достаточно рестарта.
# Рестарт сам прогонит migrate + collectstatic (подхватит guest.css и новую сборку staff).
docker compose restart web

# Проверить, что всё поднялось
docker compose ps        # web должен быть Up (healthy)
```

Полный холодный старт — как обычно по RUNBOOK.md (`docker compose up -d` → `migrate` → `seed_bar`).

### Проверка после рестарта

1. Гость: открой `http://<IP>:8000/menu/n/1/` — новая страница: Витрина / Меню / Сервис,
   карточки без фото, «Позвать официанта» → на планшете персонала стол подсветится,
   «Отменить вызов» — бейдж погаснет.
2. Персонал: `http://<IP>:8000/staff/` — на iPhone, если PWA показывает старую версию,
   закрой приложение полностью и открой заново (service worker подтянет новую сборку).
3. Сквозной тест бара: прими заказ с пивом + едой → в «Заказы» пиво в вкладке БАР,
   еда в КУХНЯ, у обоих идёт таймер.

QR-коды перепечатывать НЕ нужно — URL столов не менялись.
