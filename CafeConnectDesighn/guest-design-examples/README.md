# Guest redesign concepts

Open `guest-redesign-concepts.html`, `guest-5-website-versions.html`, or `guest-5-more-functional-ideas.html` in a browser.

`guest-redesign-concepts.html` contains three standalone guest UI directions:

- `Comfort Polish`: closest to the current guest design, safer to implement incrementally.
- `Revolut-Style Hub`: action-first home screen with table/session context and quick service actions.
- `Immersive Restaurant`: stronger branded profile with more atmosphere and fewer visible UI frames.

`guest-5-website-versions.html` contains five more distinct website directions:

- `Ticket Receipt`
- `Counter Pop`
- `Concierge Card`
- `Evening Gallery`
- `Menu Ledger`

`guest-5-more-functional-ideas.html` contains five function-first directions:

- `Table Assistant`
- `Allergen First`
- `Dish Carousel`
- `Command Palette`
- `Large Type Mode`

The files are plain HTML, CSS, and JavaScript. They do not change the current `CafeConnect Гость.dc.html` prototype.
